Patterns

#
Name & Schritte
Aktion
Spalten-Erklärung (Schritte innerhalb eines Patterns):
  • Dauer (ms): Wie lange der Schritt läuft (Millisekunden).
  • Level (0–255): Zielhelligkeit; 0 = aus, 255 = volle Helligkeit.
  • Fade: „true“ = weicher Übergang (Rampe) zur Zielhelligkeit; „false“ = harter Sprung.
  • Aktion: Schritt entfernen.
Hinweis: Der letzte Schritt gilt als Pause/Ruhezeit des Musters.

Gruppen

ID
Name / Status
Aktion
Spalten-Erklärung (Gruppen):
  • ID: Eindeutige Gruppennummer (frei wählbar).
  • Name / enabled: Anzeigename; „enabled“ an/aus schaltet die gesamte Gruppe (Zeit wird eingefroren).
  • Aktion: Gruppe löschen.

Ausgänge

#
Konfiguration
Aktion
Spalten-Erklärung (Ausgänge):
  • GPIO: Pin-Nummer am ESP32.
  • LEDC ch: PWM-Kanal (0–15); jeder Ausgang braucht einen eigenen Kanal.
  • Pattern: Verknüpftes Blinkmuster.
  • Rest ms (-1=Pat): Dauer des letzten Schritts (Pause). -1 = Pause aus Pattern übernehmen.
  • Gruppe: Gruppennummer; Gruppen können komplett an/aus geschaltet werden.
  • Phase ms: Zeitverschiebung innerhalb eines Pattern-Zyklus (für versetztes Blinken).
  • Aktion: Ausgang löschen.
